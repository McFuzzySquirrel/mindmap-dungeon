# Mindmap Dungeon App Workspace

This folder contains the architect-owned desktop app baseline for Foundation Phase 1.

## Commands

- `npm run dev` - start Vite dev server
- `npm run typecheck` - strict TypeScript validation
- `npm run test` - run Vitest in CI mode
- `npm run build` - typecheck and bundle frontend
- `npm run tauri:dev` - run Tauri desktop app in development
- `npm run tauri:build` - build desktop bundles

## Scope

This baseline intentionally includes only platform scaffolding and shell entry points.
Business logic, persistence internals, and feature implementations are owned by specialist agents.
